浸透流 これだけ(練習の前に読む)

基礎(スライドの流れどおり)

水頭の定義Bernoulli:½ρwv² + ρwgz + p = E(運動・位置・圧力エネルギー)。ρwg で割ると hv + hz + hp = h(速度水頭 v²/2g、位置水頭 z、圧力水頭 p/γw)
地下水の全水頭流れがきわめて遅く速度水頭は無視できる → h = hz + hp
動水勾配と Darcyi = Δh/Δl(2点の水頭差 ÷ 流れた距離)、v = ki(流速は動水勾配に比例、k:透水係数)、Q = Av
連続条件式微小要素 dxdy で流入 = 流出(水は非圧縮)→ ∂vx/∂x + ∂vy/∂y = 0
支配方程式vx = −k ∂h/∂x、vy = −k ∂h/∂y を連続式に代入、k 一定 → ∂²h/∂x² + ∂²h/∂y² = ∇²h = 0(Laplace の式)
ポテンシャル関数Φ = −kh とおくと vx = ∂Φ/∂x、vy = ∂Φ/∂y(Φ の勾配が流速)。Φ も Laplace 式を満たす
等ポテンシャル線と流線等ポテンシャル線(Φ = 一定)と流線(Ψ = 一定)は直交する
フローネット互いに直交する等ポテンシャル線と流線群で流れの場を区切ったもの。正方形セル(d×d)なら q = k(Δh/d)d = kΔh → 全てのセルで流量と水頭損失が等しい

計算の共通ルール

流量 Q = 面積 × v。Dupuit の仮定:勾配が緩やかなので、高さによらず流速が同じとみなす。
導出の型(全部同じ):① Q = 面積 × k × 勾配 を立てる → ② 変数分離 → ③ 積分して +C → ④ 境界値を2つ代入 → ⑤ 引き算して C を消す

4つの式

対象① 立てる式(面積の意味)③ 積分後答え
締切堤Q = −kz dz/dx
(断面 z×1。x 方向に水位が下がるので −)		Qx = −kz²/2 + CQ = k(H₁²−H₂²)/(2B)
重力井戸Q = 2πrkh dh/dr
(円筒面 2πr × 高さ h)		Q ln r = πkh² + CQ = πk(h₂²−h₁²)/ln(r₂/r₁)
掘り抜き井戸Q = 2πrkD dh/dr
(円筒面 2πr × 帯水層厚 D、一定)		Q ln r = 2πkDh + CQ = 2πkD(h₂−h₁)/ln(r₂/r₁)
堤体の近似解Q = kz dz/dx、dz/dx = tanβ、z = λsinβ
→ Q = kλ sinβ tanβ		Qx = kz²/2 + Cλ = l/cosβ − √(l²/cos²β − H²/sin²β)
Q = kλ sinβ tanβ
揚水試験で k を聞かれたら、答えの式を k について解く(重力井戸:k = Q ln(r₂/r₁)/{π(h₂²−h₁²)}、掘り抜き:k = Q ln(r₂/r₁)/{2πD(h₂−h₁)})。

近似解の境界値(ここだけ覚える)

x = l で z = H → Ql = kH²/2 + C …(4)
浸出点 x = λcosβ、z = λsinβ → C = kλ²sin²β/2 …(6)
(4)に入れて整理 → λ² − (2l/cosβ)λ + H²/sin²β = 0 → λ < l なので − の解

フローネット

Q = k × (H/Nd) × Nf Nf = 流路の数、Nd = 水頭が下がる区切りの数(分母)
例:k = 2.00×10⁻⁵ m/s、H = 30 m、Nf = 3、Nd = 10 → 1.8×10⁻⁴ m³/s × 86400 = 15.5 m³/day/m

落とし穴

・積分の +C を忘れない ・ln(自然対数)を使う ・重力井戸は h²、掘り抜きは h ・「1日当たり」は ×86400 ・2:1 の法面は tanβ = 1/2、sinβ = 1/√5、cosβ = 2/√5

浸透流 計算練習(授業内レポート型)

範囲:重力井戸・掘り抜き井戸・締切堤・堤体のフローネットと近似解 / 時間40分 / 導出は「式を立てる → 変数分離 → 積分(+C)→ 境界条件2つ → 引き算」の順で

A. 導出(白紙から書く)

問1 重力井戸(不圧帯水層)で、Dupuit の仮定から Q = 2πrkh dh/dr を立てた理由を説明し、そこから k = Q/{π(h₂²−h₁²)}·ln(r₂/r₁) と Q を導け。
問2 掘り抜き井戸(被圧帯水層、厚さ D)で、Q = 2πrkD dh/dr を立て、k と Q を導け。重力井戸の式との違い(h が D になる理由)も述べよ。
問3 締切堤(幅 B、上流水位 H₁、下流水位 H₂)の単位幅流量 Q = k(H₁²−H₂²)/(2B) を、Q = −kz dz/dx から導け。なぜマイナスがつくのかも述べよ。
問4 堤体内の流量の近似解を導け。Q = kz dz/dx …(1)、浸出側の法面も浸潤面:dz/dx = tanβ、z = λsinβ から始め、λ = l/cosβ − √(l²/cos²β − H²/sin²β) と Q = kλ sinβ tanβ を示せ。± のうち − を選ぶ理由も書くこと。

B. 数値計算(単位に注意)

問5(フローネット・授業スライド)図の堤体で H = 30.0 m、k = 2.00×10⁻⁵ m/s、流路数 Nf = 3、等ポテンシャル線の間隔数 Nd = 10 とする。単位奥行き当たり、1日当たりの漏水量を求めよ。
問6(フローネット)H = 20 m、k = 1.0×10⁻⁵ m/s、Nf = 4、Nd = 12 のとき、単位奥行き・1日当たりの漏水量を求めよ。
問7(近似解・復習問題)ダム高 H = 32 m、l = 104.0 m、浸出側法面勾配 2:1、k = 30.0 m/day のとき、λ と Q を求めよ。
問8(近似解)H = 20 m、l = 60 m、浸出側法面勾配 2:1、k = 1.0×10⁻⁵ m/s のとき、λ と 1日当たりの Q を求めよ。
問9(重力井戸の揚水試験)揚水量 Q = 0.010 m³/s。観測井 r₁ = 10 m で h₁ = 8.0 m、r₂ = 40 m で h₂ = 9.0 m。透水係数 k を求めよ。
問10(重力井戸)k = 2.0×10⁻⁴ m/s、r₁ = 10 m で h₁ = 8.0 m、r₂ = 50 m で h₂ = 9.0 m のとき、Q を m³/s と m³/day で求めよ。
問11(掘り抜き井戸の揚水試験)帯水層厚 D = 6.0 m、Q = 0.0050 m³/s、r₁ = 10 m で h₁ = 20.0 m、r₂ = 60 m で h₂ = 21.5 m。k を求めよ。
問12(締切堤)k = 10 m/day、H₁ = 6.0 m、H₂ = 2.0 m、B = 40 m のとき、単位幅流量 Q を求めよ。

解答

A. 導出

問1 Dupuit の仮定:全水頭の勾配が緩やかなので、等ポテンシャル線を鉛直とみなし、高さによらず流速が同じ(v = k dh/dr)。井戸から距離 r の円筒面(半径 r、高さ h)を通る流量は、面積 2πrh × 流速 → Q = 2πrkh dh/dr。
変数分離:Q dr/r = 2πkh dh。Q は r によらず一定なので積分して Q ln r = πkh² + C。
境界値:r = r₁ で h = h₁ → Q ln r₁ = πkh₁² + C …(1)、r = r₂ で h = h₂ → Q ln r₂ = πkh₂² + C …(2)。
(2)−(1):Q(ln r₂ − ln r₁) = πk(h₂² − h₁²) → k = Q/{π(h₂²−h₁²)}·ln(r₂/r₁)、Q = πk(h₂²−h₁²)/ln(r₂/r₁)。
問2 被圧帯水層では、上が不透水層なので、水が通る高さは常に帯水層厚 D。円筒面積 2πrD × v(= k dh/dr)→ Q = 2πrkD dh/dr。Q dr/r = 2πkD dh → Q ln r = 2πkDh + C。境界値を代入し (2)−(1):Q(ln r₂ − ln r₁) = 2πkD(h₂ − h₁) → k = Q/{2πD(h₂−h₁)}·ln(r₂/r₁)、Q = 2πkD(h₂−h₁)/ln(r₂/r₁)。
違い:重力井戸は断面の高さ h 自体が変わるので h dh を積分して h²/2 になり、h² の差が出る。掘り抜き井戸は D が一定なので h の差になる。
問3 断面積 z×1、v = k×(動水勾配)。x の正の向きに進むと水位 z が下がる(dz/dx < 0)ので、流量を正にするためマイナスをつける:Q = vz = −kz dz/dx。定常で Q 一定、積分:Qx = −kz²/2 + C。x = 0 で z = H₁ → C = kH₁²/2。x = B で z = H₂ → QB = −kH₂²/2 + kH₁²/2 → Q = k(H₁²−H₂²)/(2B)。
(井戸と問4は、r や x を水が流れてくる側に向けて取っているので勾配が正になり、マイナスはつかない。)
問4 浸出点の高さ z = λ sinβ、勾配 dz/dx = tanβ を (1) に代入:Q = kλ sinβ tanβ …(2)。(1)を積分:Qx = kz²/2 + C …(3)。
境界1:x = l で z = H → Ql = kH²/2 + C …(4)。境界2(浸出点):x = λcosβ、z = λsinβ → Qλcosβ = kλ²sin²β/2 + C …(5)。
(5)に(2):kλ² sinβ cosβ tanβ = kλ² sin²β なので C = kλ²sin²β − kλ²sin²β/2 = kλ²sin²β/2 …(6)。
(4)に(2)(6):(kλ sinβ tanβ) l = kH²/2 + kλ²sin²β/2。k で割り、2/sin²β をかける(sinβ tanβ = sin²β/cosβ)と
λ² − (2l/cosβ)λ + H²/sin²β = 0 → λ = l/cosβ ± √(l²/cos²β − H²/sin²β)。
浸出点は堤体内にあり λ < l なので − を選ぶ(+ だと λ > l/cosβ > l になる):λ = l/cosβ − √(l²/cos²β − H²/sin²β)、Q = kλ sinβ tanβ。

B. 数値計算

問5 Q = k(H/Nd)Nf = 2.00×10⁻⁵ × 30.0/10 × 3 = 1.80×10⁻⁴ m³/s/m。×86400 s → 15.5 m³/day/m(スライドと一致)。
問6 Q = 1.0×10⁻⁵ × 20/12 × 4 = 6.67×10⁻⁵ m³/s/m × 86400 = 5.76 m³/day/m。
問7 2:1 → tanβ = 1/2、sinβ = 1/√5、cosβ = 2/√5。λ = 104.0/(2/√5) − √(104.0²/(4/5) − 32²/(1/5)) = 116.28 − √(13520 − 5120) = 116.28 − 91.65 = 24.62 m。Q = 30.0 × 24.62 × (1/√5) × (1/2) = 165 m³/day/m。(フローネットでは 150。先生「どちらも正しい」)
問8 λ = 60/(2/√5) − √(60²×5/4 − 20²×5) = 67.08 − √(4500 − 2000) = 67.08 − 50.00 = 17.08 m。Q = 1.0×10⁻⁵ × 17.08 × 0.4472 × 0.5 = 3.82×10⁻⁵ m³/s/m × 86400 = 3.30 m³/day/m。
問9 k = Q/{π(h₂²−h₁²)}·ln(r₂/r₁) = 0.010/{π(81 − 64)} × ln4 = 0.010/53.41 × 1.386 = 2.60×10⁻⁴ m/s。
問10 Q = π × 2.0×10⁻⁴ × (81 − 64)/ln5 = 0.01068/1.609 = 6.64×10⁻³ m³/s = 573 m³/day。
問11 k = Q/{2πD(h₂−h₁)}·ln(r₂/r₁) = 0.0050/(2π × 6.0 × 1.5) × ln6 = 0.0050/56.55 × 1.792 = 1.58×10⁻⁴ m/s。
問12 Q = 10 × (36 − 4)/(2 × 40) = 4.0 m³/day/m。

よくある間違い

間違い対策
積分定数 C を忘れる積分したら必ず「+ C」。境界値2つを引き算して消す
log と ln の混同井戸の式は自然対数 ln。電卓は「ln」キーを使う(log₁₀ だと約2.3倍ずれる)
重力井戸で h²、掘り抜き井戸で h を取り違える断面の高さが変わる(h)か一定(D)かで判断
m³/s のまま答える「1日当たり」なら ×86400(= 24 × 60 × 60)
近似解で + の解を選ぶ浸出点は λ < l なので −
Nf と Nd を逆にするNf = 流路(流線で区切った帯)の数、Nd = 水頭が下がる区切りの数。Nd が分母
