3. 斜面災害の定義(暗記)

地すべり:主に土質・地質構造的特性と力学要因で、斜面が比較的広い範囲にわたって滑動
土石流:土砂・礫が水と混合し、渓床堆積物とともに渓岸を削りながら5〜20 m/sで流下
斜面崩壊:地すべりより小規模で急傾斜部が比較的急速に崩れる(がけ崩れ含む)
急傾斜地崩壊危険区域:傾斜30°以上・高さ5m以上のがけで5戸以上の人家や公共施設に被害の恐れ。一定の行為を禁止・制限。県知事が指定
斜面=自然 / 法面=人が手を加えた
地すべり(コーヒーカップ)斜面崩壊(スペースマウンテン)
地質特定地質・地質構造に多い地質と関係なし
土質粘性土がすべり面砂質土(マサ・ヨナ・シラス)
地形5〜20°の緩傾斜20°以上の急傾斜、遷急線付近
活動継続的・反復、時間依存大突発的、時間依存小
速度0.01〜10mm/day、小さい10mm/day以上、極めて大
土塊乱れ少、原形保つ攪乱される
誘因地下水の影響大降雨(強度)
規模1〜100ha、大小
徴候亀裂・陥没・隆起・地下水変化あり前兆なし
斜面が不安定になる3原因
①斜面勾配の不適(人為。切土・盛土の設計勾配の設定不適)
②滑動荷重の増加(降雨で単位体積重量↑、地震のせん断力、法肩付近の構造物)
③せん断強度の低下(降雨・地下水浸透→間隙水圧↑)
対策 砂防ダム:土砂を止める。天端まで満砂すると機能しない(スリット式・重力式)
法面工:ロックボルト、永久アンカー+独立受圧板、吹付法枠(草を生やして自然感)

5. 安全率(計算)

Fs = 抵抗側 / 起動側(Fs>1.0で安定)。せん断力法 Fs=SR/SA、モーメント法 ΣMR/ΣMA
無限斜面(単位幅、側面力Pは釣合って無視)
地下水なし:SA = γt z sinα, SR = c'/cosα + γt z cosα tanφ'
Fs = [c'/cos²α + γt z tanφ'] / [γt z tanα]
地下水あり(滑り面からH):W=γt(z−H)+γsat H
SA = {γt(z−H)+γsat H} sinα
SR = c'/cosα + {γt(z−H)+(γsat−γw)H} cosα tanφ'
Fs = [c'/cos²α + {γt(z−H)+(γsat−γw)H} tanφ'] / [{γt(z−H)+γsat H} tanα]
※SAはγsat H、SRは(γsat−γw)H(水に浮力、揚圧力U=γw H cosα)
特別な場合式
砂 c'=0、H=0Fs=tanφ'/tanα → α≦φ'で安定
粘土 φ=0Fs=2c/(γt z sin2α) → z<2c/(γt sin2α)で安定
H=z、c'=0Fs=(γsat−γw)tanφ'/(γsat tanα)
例:φ'=30°、α=28°、γ=17.6、γw=9.8:H=0→1.09、H=z→0.48(水位上昇でα<φ'でも不安定)。砂ではzが約分される
Fellenius法(スウェーデン法、スライス間力を無視、円弧)
抵抗 SRi = c li + Wi cosαi tanφ、起動 Wi sinαi(Wi=γ×Ai)
Fs = Σ(c li + Wi cosαi tanφ) / Σ Wi sinαi
表の作り方:h(深さ)→A(面積)→θ→α(両端θの平均)→W=γA→Wsinα、Wcosα
授業の例題(ρt=1.6t/m³、c=25kN/m²、φ=5°、r=14m、中心角118°、7スライス):
γ=ρ×9.81=15.696、弧長 l=r×θ(rad)=14×118π/180=28.83m、Σcl=c×l=720.82、ΣWsinα=688.62、ΣWcosα tanφ=154.32 → Fs=(720.82+154.32)/688.62=1.27
※粘着力cは全弧長に一様に効く(スライスごとに分けず c×全弧長でよい)。αは各スライス底面の傾き(中心角θに等しい)、右(上り)側は正、左(下り)側は負
円弧の幾何(黒板):中心O、最下点からの高さ y=r(1−cosθ)、水平位置 x=r sinθ、スライス底面の傾きα=θ(接線と水平のなす角=半径と鉛直のなす角)、底面長 l=b/cosα。スライス高 h=地表の高さ−円弧の高さ
演習(第4回、10スライス、θ表から):円弧の高さ y=11.49−14cosθ、h=地表−y、α=両端θの平均、W=1.7×9.81×A=16.66A(c=16、φ=2°、幅2m、最後のみ2.88m、最後の面積は三角形で近似)→ Σcl=397.9、ΣWcosα tanφ=41.3、ΣWsinα=366.4 → Fs≒1.2

6. 浸透流

Darcy:v=ki(i=Δh/L)、Q=kiA。Dupuitの仮定:流線=浸潤面と不透水層上面、等ポテンシャル線は鉛直、動水勾配は浸潤面勾配 i≒dz/dx(準一様流:高さによらず流速同じ)→計算が楽
フローネット Q = k Δh Nf/Nd
浸潤面(縦断面) Q=−k z dz/dx → 積分(C!)→ Q = k(H₁²−H₂²)/(2B)
アースダム近似式 Q=k λ sinβ tanβ、λ=l/cosβ−√(l²/cos²β−H²/sin²β)
復習問題:k=30m/day、H=32m、Nf=5、Nd=32 → 150m³/day/m、近似式 約165(どちらも正しい、真値は不明)
重力井戸(不圧、Q=2πr k h dh/dr)
Q = πk(h₂²−h₁²) / ln(r₂/r₁)
掘り抜き井戸(被圧、厚さD、Q=2πr k D dh/dr)
Q = 2πkD(h₂−h₁) / ln(r₂/r₁)
導出の流れ:Qを式に→変数分離(Qは一定)→積分(定数C)→境界条件2つ(r₁,h₁)(r₂,h₂)→引き算でC消去

7. 堤防の破壊

形態流れ
越流(越水)水が堤防を越える→裏法尻が洗掘→裏法が崩れ決壊
洗掘強い流れの力で堤防の土が流失→大部分が崩壊
浸透破壊降雨・河川水が堤防内に浸透→堤体内水位↑→弱化→崩壊
パイピング浸透水が通り道(パイプ)をつくり土粒子を運ぶ
洗掘が起こりやすい箇所:①川の屈曲部(外カーブ。遠心力で水位↑)②合流点付近(逆流、支川堤防は弱い)③狭窄部(上流で水位↑→越流)④橋・堰の上流(せき上げ)→遊水地などで対策
浸透破壊に強い堤防:高さ高い・敷幅広い・法面勾配緩い・平均動水勾配小さい
浸透対策:断面拡大工法(川表に難透水性、川裏に透水性材料)/ドレーン工法/表法被覆工法/全面被覆工法
