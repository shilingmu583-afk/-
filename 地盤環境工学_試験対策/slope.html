安全率の考え方(スライド)

モーメントの釣合いFs = MR/MA(すべりに抵抗する力のモーメント / すべりを起こそうとする力のモーメント)
せん断力の釣合いFs = SR/SA(すべりに抵抗するせん断力 / すべりを起こそうとするせん断力)
安定条件斜面内のいたる所で Fs > 1.0
安定解析斜面内で安全率が最小となるすべり面を探索すること

無限斜面(単位幅の土塊、l cosα = 1、側面の力 P は釣り合うので無視)

地下水なし地下水あり(すべり面から高さ H)
重さ Wγtzγt(z−H) + γsatH
滑動力 SA = W sinαγtz sinα{γt(z−H) + γsatH} sinα
抵抗力 SR = cl + R tanφc/cosα + γtz cosα tanφc'/cosα + {γt(z−H) + (γsat−γw)H} cosα tanφ'
Fs(分子分母を cosα で割る)[c/cos²α + γtz tanφ] / [γtz tanα][c'/cos²α + {γt(z−H) + (γsat−γw)H} tanφ'] / [{γt(z−H) + γsatH} tanα]
・l = 1/cosα(すべり面の長さ)。c はすべり面の面積 l×1 にかかる
・滑動力は水を含む重さ(γsat)、抵抗力は浮力を引いた有効応力(γsat−γw)
・砂 c = 0:Fs = tanφ/tanα → α < φ で安定(z は約分。安息角 = 内部摩擦角)
・粘土 φ = 0:Fs = 2c/(γtz sin2α) → z < 2c/(γt sin2α)(限界深さがある)

円弧すべり:Fellenius 法(スウェーデン法)

斜面をスライスに分割し、比較的影響の少ないスライス側面の力 Ei を無視。円弧の中心 O 回りのモーメントの釣合い。
滑動モーメント MAi = Wi r sinαi　抵抗力 Pi = Wi cosαi、SRi = cli + Pi tanφ　抵抗モーメント MRi = SRi r
Fs = ΣMR/ΣMA = Σ(cli + Wi cosαi tanφ) / ΣWi sinαi(r は約分)
表の作り方:Ai, αi → sinα, cosα → W = ρ × 9.81 × A → W sinα、W cosα、W cosα tanφ → 合計。Σcl = c × 弧長(弧長 = r × 中心角[rad])

落とし穴

・c ≠ 0 なら必ず γ = ρg(ρ のままだと Fs が10倍近くずれる)。c = 0 の比だけの式なら g は約分されて ρ のままでよい
・角度は電卓を DEG にする・α が負のスライスは W sinα も負(止める側)・安全率が 10 を超えたら g を疑う
・最後は「Fs > 1.0 で安定 / < 1.0 で不安定」と判定まで書く

斜面安定 計算練習(授業内レポート型)

時間40分 / γw = 9.81 kN/m³ / 判定まで書く

A. 導出

問1 単位幅の土塊(深さ z、傾斜角 α、地下水なし)について、W、SA、SR を図とともに示し、Fs = [c/cos²α + γtz tanφ]/[γtz tanα] を導け。
問2 すべり面から高さ H まで地下水があるときの Fs を導け。滑動力に γsat、抵抗力に γsat−γw を使う理由も述べよ。
問3 (1)c = 0 の砂の斜面が安定である条件を求めよ。(2)φ = 0 の粘土の斜面が安定である深さ z の条件を求めよ。
問4 Fellenius 法の安全率の式を、スライスに働く力(Wi、Pi、SRi)と中心 O 回りのモーメントから導け。

B. 数値計算

問5(演習④⑤)地下水のない表層 3 m の半無限一様な c' = 0、φ' = 30° の砂質地盤で、傾斜角 28° の斜面の Fs を求めよ。また、豪雨で地表まで水位が上昇したときの Fs を求めよ(ρsat = ρt = 1.8 t/m³)。
問6(問5の数値替え)c' = 0、φ' = 35°、α = 30°、z = 4 m、ρsat = ρt = 1.9 t/m³。地下水なしと、地表まで水位が上昇したときの Fs を求めよ。
問7(φ = 0)c = 20 kPa、γt = 17 kN/m³、α = 20° の粘土斜面が安定である深さの条件を求めよ。
問8(c ≠ 0、地下水あり)c' = 5 kPa、φ' = 30°、α = 25°、z = 3 m、H = 1.5 m、ρt = 1.7 t/m³、ρsat = 1.9 t/m³ のとき Fs を求めよ。
問9(Fellenius・授業の例題)ρt = 1.6 t/m³、c = 25 kN/m²、φ = 5°、r = 14 m、中心角 118°。A(m²)= 19.32, 39.83, 26.97, 19.73, 12.08, 7.65, 2.82、α(°)= 48.35, 34.58, 19.78, 6.78, −4.46, −16.90, −31.24。表を完成させて Fs を求めよ。

解答

問1 W = γtz(幅1×深さz)。SA = W sinα = γtz sinα。R = W cosα、l = 1/cosα(l cosα = 1)。SR = cl + R tanφ = c/cosα + γtz cosα tanφ。Fs = SR/SA の分子分母を cosα で割り、Fs = [c/cos²α + γtz tanφ]/[γtz tanα]。
問2 W = γt(z−H) + γsatH、SA = W sinα。有効垂直力 U' = W cosα − γwH cosα = {γt(z−H) + (γsat−γw)H} cosα、SR = c'l + U' tanφ'。cosα で割って Fs の式。理由:すべらせるのは水を含む土塊全体の重さ。摩擦に効くのは間隙水圧(浮力)を引いた有効応力だから。
問3 (1)Fs = tanφ/tanα > 1 ⇔ α < φ。(2)Fs = c/(γtz sinα cosα) = 2c/(γtz sin2α) > 1 ⇔ z < 2c/(γt sin2α)。
問4 側面力 Ei を無視。滑動モーメント MAi = Wi r sinαi。底面の垂直力 Pi = Wi cosαi、抵抗力 SRi = cli + Pi tanφ、抵抗モーメント MRi = SRi r。Fs = ΣMR/ΣMA で r が約分され Fs = Σ(cli + Wi cosαi tanφ)/ΣWi sinαi。
問5 地下水なし:Fs = tan30°/tan28° = 0.5774/0.5317 = 1.09 > 1.0 安定。水位上昇(H = z):Fs = (1.8−1.0)/1.8 × 1.086 = 0.48 < 1.0 不安定(g は約分されるので ρ のままでよい)。
問6 地下水なし:tan35°/tan30° = 1.21 安定。水位上昇:(1.9−1.0)/1.9 × 1.213 = 0.57 不安定(z = 4 m は約分される)。
問7 z < 2c/(γt sin2α) = 40/(17 × sin40°) = 40/10.93 = 3.66 m。
問8 c ≠ 0 なので γ = ρg:γt = 16.68、γsat = 18.64 kN/m³。分子 = 5/cos²25° + (16.68×1.5 + 8.83×1.5) tan30° = 6.09 + 22.09 = 28.18。分母 = (16.68×1.5 + 18.64×1.5) tan25° = 52.98 × 0.4663 = 24.70。Fs = 1.14 > 1.0 安定。
問9 γt = 1.6 × 9.81 = 15.696。
