地盤環境工学 まとめノート(試験 11/10)

全体の流れ:①地盤の成り立ち→②斜面はなぜ崩れるか→③崩れにくさを数値(安全率)で測る→④水の流れ(浸透)→⑤堤防。すべて「抵抗する力÷起こそうとする力」と「水が有効応力を減らす」の2つの考え方でつながる。

0. 土質力学の土台(全章で使う)

σ = σ' + u(全応力=有効応力+間隙水圧)　τf = c' + σ' tanφ'(せん断強さ)
  • 土の強さを決めるのは水を除いた粒子どうしの力 σ'。水圧 u が増えると σ' が減り、強さ τf が下がる。
  • 砂(c'=0)は強さが σ' に比例 → 水位上昇の影響を最も受ける(液状化も同じ原理)。粘土(φ=0)は強さが c だけ。
  • 水中の土は浮力で軽くなる:γ' = γsat − γw。水位下の有効応力 σ' = γt(z−H) + γ'H。
  • 水位がΔh低下すると σ' は (γt−γsat+γw)Δh 増える(例:1.7−1.8+1.0=0.9Δh)。

2. 斜面災害

斜面=自然にできたもの、法面=人が手を加えたもの。盛土・切土をするのは、土を運ぶ量を減らして運搬コストを抑えたいから。法面対策:ロックボルトで一体化して支える、吹付法枠で表面を押さえ草を生やして自然感を出す。

定義(暗記)

  • 地すべり:主として地質構造的特性と力学要因によって、斜面が比較的広い範囲にわたって滑動するもの。
  • 土石流:山体を構成する土砂や礫の一部が水と混合し、河床堆積物とともに渓岸を削りながら急速(5〜20 m/s)に流下する現象。
  • 斜面崩壊:地すべりに比べ小規模で、急傾斜部分で比較的急速に崩壊(広義では地すべりも含む)。
  • 急傾斜地崩壊危険区域:傾斜30°以上・高さ5m以上のがけで、5戸以上の人家や公共施設に被害の恐れ。県知事が指定し、一定の行為を禁止・制限(法律:急傾斜地の崩壊による災害の防止に関する法律)。
地すべり斜面崩壊
地質・土質特定の地質・構造、粘性土がすべり面地質と無関係、砂質土(マサ・ヨナ・シラス)
地形5〜20°の緩傾斜20°以上の急傾斜地の0次谷・谷頭部
活動・速度継続・再発、0.01〜10mm/day突発、10mm/day以上
土塊・規模原型を保つ、1〜100ha攪乱される、小規模
誘因・徴候地下水、亀裂・陥没・隆起あり降雨強度、前兆なし
覚え方:地すべり=ゆっくり大きく(コーヒーカップ)、斜面崩壊=突然小さく速く(スペースマウンテン)。

斜面が不安定になる3原因

  • ①斜面勾配の不適(主に人為的要因。切土・盛土の設計勾配)
  • ②滑動荷重の増加(降雨で単位体積重量↑、地震のせん断力、法肩の構造物。主に自然的要因)
  • ③せん断強度の低下(降雨・地下水浸透で間隙水圧↑。主に自然的要因)

対策:砂防ダム(土砂を止める。満砂すると機能しない)、法面工(ロックボルト、永久アンカー+独立受圧板、吹付法枠)。事例:2014年広島市安佐南区の土石流。

すべり面の形と破壊形態

  • すべり面:円弧(厚く均質な粘性土)/平面(粘着力小の砂質土、硬い基盤上の薄い表層)/非円弧。
  • 斜面先破壊:砂質土。斜面先は応力集中が起きやすく土被り圧も小さい→浅いすべり。底部破壊:粘着力の大きい土。深さ方向の強さの増加がせん断力の増加より小さい→斜面先より前方・深い位置。斜面内破壊:硬質地盤が浅い位置にあり、その層に規定される。

3. 安定解析(計算の中心)

Fs = 抵抗する力 / 起こそうとする力。Fs>1 で安定、Fs=1 が限界。安定解析=Fsが最小となるすべり面を探すこと。
モーメント釣合い Fs=MR/MA、せん断力釣合い Fs=SR/SA。

3-1 無限斜面(すべり面が斜面と平行)

単位幅の土塊(l cosα=1)。両側面の力Pは釣り合うので無視。

  • 地下水なし:W=γt z、SA=W sinα、SR=c'l+R tanφ'(R=W cosα, l=1/cosα)
Fs = [c'/cos²α + γt z tanφ'] / [γt z tanα]
  • 地下水あり(滑り面からH):W=γt(z−H)+γsat H。SAは土塊全体の重さ(水を含む)で γsat H。SRは有効垂直力U'(揚圧力 U=γw H cosα を引く)なので (γsat−γw)H。
Fs = [c'/cos²α + {γt(z−H)+(γsat−γw)H} tanφ'] / [{γt(z−H)+γsat H} tanα]
条件結果と意味
砂 c'=0、H=0Fs=tanφ'/tanα → α≦φ'で安定。zが約分される。安息角=自然にとりうる土の最大傾斜角(砂では内部摩擦角)
粘土 φ=0Fs=2c/(γt z sin2α) → z<2c/(γt sin2α)。深くなると自重(滑動力)だけ増え、強さcは一定→必ず限界深さがある
H=z、c'=0Fs=(γsat−γw)tanφ'/(γsat tanα)。有効応力が約半分
数値例:c'=0、φ'=30°、α=28°。H=0→Fs=1.09(わずかに安定)。H=z(豪雨で地表まで水位上昇)→Fs=0.48(不安定)。α<φ'でも水位上昇で崩れる。変わるのは土の種類ではなくuとσ'だけ。

3-2 円弧すべり(Fellenius法=スウェーデン法)

斜面をスライスに分割し、比較的影響が小さいスライス側面の力Eiを無視。円弧中心O回りのモーメントを考える。

  • 滑動モーメント MAi=Wi r sinαi、Pi=Wi cosαi、SRi=c li+Pi tanφ、抵抗モーメント MRi=SRi r(rは約分)
Fs = ΣMR/ΣMA = Σ(c li + Wi cosαi tanφ) / Σ Wi sinαi
  • 円の幾何:最下点からの高さ y=r(1−cosθ)、スライス底面の傾き α=θ(接線⊥半径)、弧長 l=rθ(rad)、スライス高 h=r(cosθi−cosθ0)。αが負(円の中心より斜面先側)なら滑りを止める側。
  • 表の作り方:h→A(台形 ½(hi−1+hi)×幅)→α(両端θの平均)→W=γA(γ=ρ×9.81)→W sinα、W cosα→W cosα tanφ。cは全弧長に一様に効く(Σcl=c×弧長)。
授業の例題(ρt=1.6、c=25、φ=5°、r=14m、118°、7スライス、のり面1:1・高さ8.4m):弧長28.83m、Σcl=720.82、ΣWsinα=688.62、ΣWcosα tanφ=154.32 → Fs=1.27(先生のExcelの面積35.83は誤り、正しくは39.83)。
演習②(ρt=1.7、c=16、φ=2°、10スライス、幅2m・最後2.88m):弧長24.87m、Σcl=397.9、ΣWsinα≈366.7、ΣWcosα tanφ≈41.3 → Fs≈1.20(スライド表の10番目A=4.31は誤り、正しくは6.20)。

4. 浸透流

  • Darcy則:v=ki、Q=kiA(i=Δh/L 動水勾配)。

地下水の基本

  • 全水頭 h=hz(位置)+hp(圧力、=p/γw)。速度水頭は地下水では非常に小さいので無視。間隙水圧 u=hp γw。
  • 連続の式 ∂vx/∂x+∂vy/∂y=0 とダルシー則から、k一定なら ∇²h=0(ラプラス方程式)。
  • 等ポテンシャル線(h=一定)と流線は直交。

フローネット

描き方:①自由に接する土の表面=等ポテンシャル線 ②不透水境界=流線 ③両者は直交 ④セルは正方形に近く。正方形セルなら全セルで流量・水頭損失が等しい(q=kΔh)。

Q = k ΔH · Nf/Nd(流路数/等ポテンシャル線で区切った数)

授業の例(止水壁、底幅8m・透水層厚4m・水深3m、Nf=4、Nd=12):k=5.28×10⁻⁴ cm/s、ΔH=300cm、Nf=4、Nd=12 → Q=5.28×10⁻⁴×300×4/12=5.28×10⁻² cm²/s=4562 cm²/day=0.456 m²/day(単位:×86400 s、1m²=10⁴cm²)。Ndは描き方で変わる(板書の網はNf=4、Nd=8で0.684 m²/day)。答えには自分で数えたNf・Ndを明記。復習問題:k=30m/day、ΔH=32m、Nf=5、Nd=32 → 150 m³/day/m。

浸潤面と Dupuit の仮定

  • 流線=浸潤面と不透水層上面、等ポテンシャル線=鉛直(aa'', bb''…)。全水頭の勾配が緩やかなら h≈z、Δs≈Δx → v=kΔh/Δs≈kΔz/Δx(高さによらず流速が同じ)。これで手計算できる。
  • 導出:Q=vz=−kz dz/dx → Qは一定なので ∫Q dx=Qx=−kz²/2+C。x=0,z=H₁ → C=kH₁²/2。x=B,z=H₂ → QB=k(H₁²−H₂²)/2。
Q = k(H₁² − H₂²) / (2B)

アースダムの近似解(Dupuit)

  • 浸出側の法面も浸潤面も傾きβ:dz/dx=tanβ、z=λ sinβ とおくと Q=kz dz/dx=kλ sinβ tanβ。積分して Qx=kz²/2+C に x=l,z=H と x=λcosβ,z=λ sinβ を代入しC消去 → λ²−(2l/cosβ)λ+H²/sin²β=0 → λ
λ = l/cosβ − √(l²/cos²β − H²/sin²β)、 Q = kλ sinβ tanβ

復習問題(H=32m、k=30m/day、法面2:1、l=123.2−19.2=104.0m):フローネット Q=kΔh Nf/Nd=30×32×5/32=150 m³/day/m、近似式 λ=24.62m、Q≒165。先生:「どちらも正しい。本当の値はわからない」(土の計算に厳密さはあまりいらない)。

井戸(導出の型は同じ:Qを式に→変数分離→積分(定数C)→境界条件2つ→引いてC消去)

  • 重力井戸(不圧):Q=2πr·k h·dh/dr → Q ln r=πk h²+C
Q = πk(h₂² − h₁²) / ln(r₂/r₁)

積分するとき定数Cをつけるのを忘れない!(重力井戸はDupuitの仮定から Q=2πr k h dh/dr)

  • 掘り抜き井戸(被圧、帯水層厚D):Q=2πr·k D·dh/dr
Q = 2πkD(h₂ − h₁) / ln(r₂/r₁)

5. 堤防

破壊形態進み方
越流水が堤防を越える→裏法尻が洗掘→裏法が崩れ決壊
洗掘強い流れで土が流失→堤防の大部分が崩壊
浸透破壊降雨・河川水が堤体に浸透→堤体内水位↑→弱化→崩壊(有効応力の低下と同じ原理)
パイピング浸透水が通り道をつくり土粒子を運ぶ
  • 洗掘が起こりやすい所:①川の屈曲部(外側)②合流点(支川堤防は弱い)③狭窄部④橋・堰の上流(せき上げ)。対策に遊水地など。
  • 浸透に強い堤防:高さが高い・敷幅が広い・法面勾配が緩い・平均動水勾配が小さい。浸透対策:断面拡大(川表に難透水・川裏に透水材)、ドレーン、表法被覆、全面被覆。
  • その他:スーパー堤防(裏法を伸ばす、地震に強い)、複合災害(盛土損壊→孤立、破堤→浸水、海岸堤防損傷→津波拡大)、ヒービング(軟弱粘性土の掘削で土留め壁外の土の重さにより底面が盛り上がる)。
